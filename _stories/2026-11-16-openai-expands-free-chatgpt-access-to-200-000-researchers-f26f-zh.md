<div class="story-lead" markdown="1">

OpenAI 宣布扩大「ChatGPT for Academic Researchers」项目，向全球 20 万名研究人员免费提供其前沿模型的使用权限。这是该项目的规模扩展，而不是新模型发布，因此变化主要体现在谁能免费用到现有的前沿模型。

公告本身只有一句话，没有说明复盖哪些模型版本、免费额度以何种形式提供（ChatGPT 界面还是 API）、申请资格与审核标准，也没有给出各国或各机构的名额如何分配。项目何时开始接受申请、现有参与者是否自动延续，同样未在公告中交代。

</div>

<div class="fact-check" markdown="1">

## 已证实与未证实

- **已证实：** OpenAI 在官方公告中表示，将把 ChatGPT for Academic Researchers 项目扩大到面向全球 20 万名研究人员，免费提供其前沿模型的使用权限；这是 OpenAI 自行宣布的项目扩展，尚无独立测试结果。
- **尚未证实：** 公告未说明具体开放日期、申请资格、可用模型版本、使用额度与项目期限；Semafor 报道的“新增 5 万份资助、先到先得、受资助者可再邀请两名合作者”目前仅见于该单一报道，OpenAI 公告未提及。

</div>

## 背景

OpenAI 此前已经在运营 “ChatGPT for Academic Researchers” 项目，这次是扩大覆盖范围，而非首次推出：按公司说法，免费使用范围将扩展到全球 20 万名研究人员。要理解这一举措，关键在 “前沿模型”（frontier models）一词，它通常指厂商当前能力最强的一代通用模型，而非为科研单独训练的专用模型；因此本次变化是使用资格和规模的调整，不是新模型或新能力的发布。

## 为什么重要

对高校和公共研究机构的研究者来说，前沿模型的订阅或 API 费用通常需要个人或课题组自行承担，这笔成本会直接限制谁能用、用多少；20 万个免费名额如果落实，等于由 OpenAI 承担这部分开销。实际的行动点是先确认自己所在机构与身份是否符合资格，并关注免费额度是否覆盖 API 调用，因为只有界面访问权限与可编程调用对计算类研究的影响差别很大。

## 后续看点

接下来值得查看的是 OpenAI 公布的申请入口与资格细则：覆盖哪些模型版本、免费额度是否包含 API、名额按何标准分配。
