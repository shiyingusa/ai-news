<div class="story-lead" markdown="1">

沃尔玛正在推出一项已投入实际运行的 Agent Gateway 服务，允许 Meta 的 AI 代理 Muse 通过沃尔玛的 Sparky 助手替用户寻找并购买黑色星期五商品。沃尔玛表示，Agent Gateway 能让 AI 代理找到相关商品，又不必共享用户的购买历史。Muse 的购买行为通过“Agent Profiles”完成，该功能在用户的沃尔玛账户内为代理活动提供独立空间，用户可设置消费上限、逐笔批准购买，并查看 Muse 买下的所有商品记录。沃尔玛称这是其上月宣布的 Agent Gateway 的首次实际部署，目前正在逐步铺开，报道未说明复盖多少用户或何时全面开放。

</div>

<div class="fact-check" markdown="1">

## 已证实与未证实

- **已证实：** 沃尔玛表示，Meta 的 Muse 可以通过 Sparky 助手和 Agent Gateway 查找并购买黑五商品，购买经“Agent Profiles”执行，用户可设消费上限、批准交易并查看购买记录（沃尔玛向 The Verge 说明）。
- **尚未证实：** 该功能具体向哪些用户、哪些地区开放，覆盖规模与全面上线时间；代理实际下单的成功率与准确性；以及是否有独立测试或用户实测数据。报道也未提及该服务是否收费或有无额外条件。

</div>

## 背景

Meta 此前推出的 Muse 是一款能代替用户执行任务的个人 AI 代理，购物和比价是其对外展示的能力之一。沃尔玛在本次黑色星期五前一个月宣布了 Agent Gateway，称它可让外部 AI 代理找到相关商品，而不必共享用户的购买历史；这次 Muse 通过 Sparky 助手接入，是该网关的一次实际购物部署。具体购买发生在沃尔玛账户内的 Agent Profiles 中，用户可在那里设置消费上限、批准购买并查看代理的购买记录。

## 为什么重要

对开发代理购物功能的团队来说，这提供了一个可参照的落地形态：代理不再直接读取用户的购买历史，而是通过平台提供的网关与账户内的独立“代理档案”获得有限权限，并由用户设置消费上限和逐笔确认。使用该功能的消费者应先检查默认消费上限与批准设置，再让 Muse 下单，并在事后核对代理档案中的购买记录。

## 后续看点

黑色星期五过后，沃尔玛是否公布该网关的使用数据，以及是否把 Agent Gateway 从 Meta Muse 扩展到其他 AI 代理提供商。
