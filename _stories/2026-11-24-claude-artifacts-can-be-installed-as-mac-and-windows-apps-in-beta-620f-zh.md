<div class="story-lead" markdown="1">

Anthropic 在 Claude 官方资源页宣布，以 beta 形式推出“Install as app”（安装为应用）功能，把用户日常使用的 Claude artifacts（在对话中生成的可交互页面或小工具）安装成 Mac 和 Windows 上的独立桌面应用，并接入系统通知。公告称这些应用还能获得“可选的完整电脑访问权限”，从而在用户电脑上做更多事情。

公告没有说明适用的订阅套餐、地区范围、是否额外收费，也没有公布 beta 转正的日期；目前这是 Anthropic 自家发布的功能说明，尚无独立测试。

</div>

<div class="fact-check" markdown="1">

## 已证实与未证实

- **已证实：** 据 Anthropic 官方公告，该 beta 功能可将 Claude artifacts 安装为 Mac 和 Windows 桌面应用，支持通知，并提供可选的完整电脑访问权限。
- **尚未证实：** 哪些套餐与地区可用、是否收费、beta 结束时间，以及“完整电脑访问”具体能读写什么、如何授权，公告均未说明，也没有独立测试或用户实测结果。

</div>

## 背景

Claude 的 artifact 是对话中生成的可交互产物，例如小工具、页面或仪表盘，过去只能在 Claude 的聊天界面里运行和预览。此次更新让这些 artifact 以独立窗口和图标的形式安装到 macOS 与 Windows 桌面上，从而可以像普通应用一样启动，并申请文件、程序、通知等操作系统权限。根据 Anthropic 的说法，该测试版正陆续向免费和付费方案的用户推出。

## 为什么重要

对已经习惯把 artifact 当小工具用的用户，产物可以不再依附浏览器标签页，作为桌面应用常驻并通过系统通知提醒；与此同时，“完整电脑访问”是一个需要用户自己把关的授权项，安装前应确认该应用实际申请了哪些权限，不要对来源不明的 artifact 开启完全访问。

## 后续看点

关注 Anthropic 何时把该功能从 beta 推向所有付费套餐，以及是否公布“完整电脑访问”的权限清单与安全限制。
