Ladybird, an independent browser built on an engine written from scratch, is now available in alpha for macOS and Linux, developer Andreas Kling announced. The release comes after more than four years of development and makes Ladybird the first browser in years to ship an entirely new engine, rather than relying on the three that dominate today: Gecko (Mozilla Firefox), Blink (Google Chrome and its derivatives) and WebKit (Safari). The build is an early alpha aimed at testing rather than daily use, and there is no Windows version yet — The Verge reports Kling says one is planned for the "later stages" of the project.

## Background

Nearly all mainstream browsers today run on just three engines — Gecko (Firefox), Blink (Chrome) and WebKit (Safari) — so a genuinely new engine has to implement web standards from scratch rather than inherit an existing codebase. Ladybird's own release plans list Linux and macOS as the targets for the 2026 alpha and a beta planned for 2027, with a native Windows port treated as a lower priority to be considered later.

## Why it matters

Web compatibility has effectively been set by three engines for more than a decade, so a fourth implementation matters to anyone who depends on one vendor's rendering decisions — site developers and standards participants now get an independent check on whether features behave the same way outside Blink, Gecko and WebKit. The practical caveat for testers is that this is alpha software on two desktop platforms only; treat it as a compatibility test bed, not a browser to migrate to.

## What to watch

Kling's next milestone posts: whether the alpha moves toward a beta, and when the Windows build promised for the project's "later stages" appears.
