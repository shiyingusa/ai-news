<div class="story-lead" markdown="1">

OpenAI 正在将 GPT-6.2 Sol 设为 ChatGPT 聊天标签页的全球默认模型。据 The Decoder 报道，OpenAI 的内部测试显示图像理解得分从 47.4% 升至 71.7%，复杂指令正确率为 78.1%，并称该模型更稳定地遵守安全策略。

上述数字均为 OpenAI 自测，未提供独立复现结果；报道也未说明 API 是否同步、各套餐的上线时间或定价变化。

</div>

<div class="fact-check" markdown="1">

## 已证实与未证实

- **已证实：** The Decoder 报道 OpenAI 已将 GPT-6.2 Sol 设为 ChatGPT 聊天标签页的全球默认模型，并引用其内部测试数据。
- **尚未证实：** 图像理解从 47.4% 升至 71.7%、复杂指令正确率 78.1% 等数字均为 OpenAI 自测，缺少独立复现；完整上线时间、API 可用性与定价未披露。

</div>

## 背景

OpenAI 在 11 月 18 日发布了 GPT-6.2 Sol，与它一同发布的还有 GPT-6.2 Astra；当时 Sol 的 API 定价为每百万输入 token 2 美元、每百万输出 token 10 美元，两个模型的上下文窗口都是 105 万 token，并且只能接收文本和图像，输出也只有文本。AI Daily Radar 11 月 19 日的日报曾报道过这次发布，以及开发者对定价的反弹；而这一次的改动在于，Sol 从可供调用的 API 模型变成了 ChatGPT 聊天标签页的全球默认模型。

## 为什么重要

普通 ChatGPT 用户会在聊天标签页直接用到新默认模型，核心变化是图像理解与复杂指令遵循；但报道未说明 API 或各订阅套餐是否同步，依赖 API 的开发者不应把这次默认模型切换视为 API 可用性变化。
