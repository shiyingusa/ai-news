<div class="story-lead" markdown="1">

开发者 Andreas Kling 于周一宣布，采用从零编写引擎的独立浏览器 Ladybird 已在 macOS 和 Linux 上进入 alpha 测试阶段，此前项目已开发四年多。当前主流浏览器基本依赖三个引擎——Gecko（Firefox）、Blink（Chrome）和 WebKit（Safari），Ladybird 因此成为多年来首个带着全新引擎面世的项目。alpha 属于早期测试版本，Windows 版本要等到项目的“后期阶段”才会推出。

</div>

<div class="fact-check" markdown="1">

## 已证实与未证实

- **已证实：** Kling 在 ladybird.org 发布公告，宣布 alpha 版面向 macOS 与 Linux 推出，项目已开发四年多（据 The Verge 报道）。
- **尚未证实：** 稳定性、网页兼容性与性能均无第三方测试数据；Windows 版本仅表示在“后期阶段”推出，没有日期；报道也未说明具体获取方式与硬件要求。

</div>

## 背景

目前主流浏览器几乎都建立在三个引擎之上：Mozilla Firefox 使用的 Gecko（2000 年随 Netscape 6 出现）、苹果 Safari 使用的 WebKit（2003 年由 KDE 的 KHTML 分支而来），以及谷歌此后从 WebKit 分叉出的 Blink。Ladybird 的官方公告强调其引擎“完全从零构建、并非分支”，这也是它被视为多年来首个全新浏览器引擎的原因。据维基百科条目，Linux 与 macOS 是 2026 年 alpha 版和计划中 2027 年 beta 版的开发目标，原生 Windows 版本并非优先事项，官方也称 alpha 版面向“不介意 bug、愿意帮忙报告问题”的早期用户。

## 为什么重要

对网页开发者和愿意尝鲜的用户来说，这是少数可以亲手验证一个非 Blink/WebKit/Gecko 引擎渲染与兼容性表现的机会；但 alpha 意味着功能不全、稳定性未知，不适合作为日常浏览器，而 Windows 用户目前完全用不上。

## 后续看点

留意 Ladybird 项目后续公告中 Windows 版本与进入 beta 阶段的时间表，以及 alpha 测试者在真实网站上的兼容性反馈。
