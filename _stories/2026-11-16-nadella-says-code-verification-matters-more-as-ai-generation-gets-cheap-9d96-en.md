In a Q&A with The Pragmatic Engineer, Microsoft CEO Satya Nadella said that as AI code generation becomes cheap, code verification becomes the more important engineering problem, because generating code is no longer the scarce step. The conversation, released as a podcast episode with a transcript on the newsletter's site, also touched on Microsoft's voluntary exit offers and on "decision models," though the excerpt gives no further detail on either.

Nadella's remarks are his argument about how software engineering should change, not a product announcement or a measured result.

## Background

Code verification is the set of checks that establish whether software does what it is supposed to: tests, code review, type checking, and static analysis. AI coding tools have shifted from autocomplete toward generating whole functions and modules, which increases the volume of generated code that must be checked before it ships.

## Why it matters

For engineering teams, the practical consequence is that review, testing and approval capacity — not code-writing speed — becomes the limit on how much AI-generated code can be safely shipped. Teams scaling generation should therefore budget for verification tooling and clear ownership of merge decisions.
